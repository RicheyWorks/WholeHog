# Release — 2026-08-21: the durability & consistency hardening release

A coordinated patch release across the seven engines whose shipped code was hardened in the tenth,
eleventh, and twelfth audit passes. Every fix in it is probe-verified; the full ecosystem builds and
tests green through the WholeHog composite. Dependencies resolve by composite `includeBuild`
(group:name), and every change here is backward-compatible, so dependents' version floors are
unchanged.

## What each version contains

**csrbt-core 0.3.1** — the tenth pass's thirteen CSRBT findings. Persistence honesty and robustness in
`FilePersistenceAdapter`: corrupt files quarantine instead of retrying forever (C5), trailing data
past a valid tree is refused (C6), the flat writer gates unencodable keys (C7), a non-atomic
filesystem fails the save rather than risk the previous snapshot (C8), orphan `.tmp` staging is swept
on open (C9), and a concurrent-delete load race resolves to ABSENT not FAILED (C12); plus the load-
validation and history fixes C1–C4. And the evolution/morph audit-correctness cluster: no phantom
morph in the audit log (C10), HYBRID scored over the seven real structures rather than a placeholder
zero (C11), and control-plane morphs recorded in the morph log (C13).

**SmokeHouse 0.2.1** — SH-1: `range()` survives a concurrent compaction commit (bounded re-resolve,
matching `get()`), and `SegmentLog.read` tolerates a cached reader channel closed under it. RP-1: a
replica applies only contiguous frames — a hole is a gap — so it can never hold a suffix without its
prefix, regardless of the tail's gap-signal timing. Also ships the pre-registered indexed-put cost
experiment and its verdict (read-on-overwrite-only).

**Twine 0.1.1** — the full durability tier. One Twine per journal directory via an exclusive lock
(T1), a durable commit point with a directory fsync (T2), the committed flag set only after the
atomic move (T3), an in-process `recover()` for a failed apply (T4), and metered empty commits (T5).

**DryAge 0.2.1** — scratch/staging never leaks on a failed view or `asOf` (D1, D2), generation release
is atomic at the timeline level and reports a partial failure (D3), and the vault issues its own
monotonic generation labels so a store rollback can neither brick preserve nor drop the newest (D4).

**SmokeSignal 0.2.1** — the wire-framing ADR: read a request whole before touching the store, close
the session on a framing error, and buffer each client request before writing (S1w–S4w). WP-1:
OP_COUNT_RANGE and OP_SIZE compute their value before writing `REPLY_VALUE`, so a throwing comparator
is a clean recoverable error, not a session desync.

**Renderer 0.1.1** — R-1: a `GroupView` whose bootstrap sweep throws unsubscribes from the tail
instead of leaking a subscriber that folds forever.

**WholeHog 0.2.1** — W-1: the `Organism` constructor unwinds its half-built resources (store,
replica, replication server, tail subscriptions) if any step fails, instead of leaking them. Carries
the audit and experiment docs for the tenth through twelfth passes.
